## Description

*User Story:*           
As a manager, I want to approve employee leave requests with an optional comment, so that employees can proceed with their planned leave.

*Acceptance Criteria:*
 - Approve button displays for each pending leave request
 - Clicking Approve opens comment dialog (optional)
 - System updates leave request status from "Pending" to "Approved"
 - Manager comment (if provided) is saved with the request
 - Employee's leave balance is deducted for the approved leave type
 - Request is removed from pending list
 - Employee can view approved status and manager comment in their history
 - Success confirmation message displays to manager
